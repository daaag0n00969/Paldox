## Полное описание

```
Paldox — оффлайн-компаньон для Palworld 1.0.

Смотрите 288 палов с правильными номерами Palpedia, планируйте разведение, изучайте навыки, предметы, башни и гайды — без постоянного интернета.

Возможности:
• Палдекс — поиск (RU/EN), фильтры по стихиям, отметка «есть у меня», расчёт статов
• Калькулятор разведения — режимы P+P, P+, =P, особые комбо
• Навыки — активные и пассивные
• Предметы — крафт, дроп, магазины, иконки оффлайн
• Боссы башен — тактика и контр-палы
• Гайды и личные заметки
• Тёмная тема, русский и английский язык

Конфиденциальность:
без аккаунтов, без рекламы, без серверной аналитики. Данные хранятся на устройстве.

Важно:
неофициальный фанатский проект. Не связан с издателем Palworld.
Товарные знаки и материалы игры принадлежат их правообладателям.

Исходный код и список изменений:
https://github.com/daaag0n00969/Paldox

Также доступно на 4PDA и GitHub Releases.
```

## Сборка для RuStore

```bat
copy keystore.properties.example keystore.properties
rem заполните пароли и путь к keystore

gradlew.bat assembleRelease
rem APK: app\build\outputs\apk\release\

gradlew.bat bundleRelease
rem AAB: app\build\outputs\bundle\release\
```

Один keystore — для RuStore, 4PDA и GitHub Releases.
